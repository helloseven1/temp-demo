# 三库字典（风格 / 组件 / 动效）

本文件是写 `spec.json` 时的**查表手册**。所有 id 都是精确字符串，写错会在生成阶段被 `build.py` 拦下。
库文件在 `02-generate-video/library/`，引擎登记表在 `library/engine.tsx`。

---

## 1. 风格库 `library/styles/<id>/`（一风格一目录，可拆多文件）

每套风格一个目录，按职责拆文件；`build.py` 按 **tokens → shell → place → title** 固定顺序内联整目录（其余文件按文件名排序追加），目录内不得重复声明同名 const：

```text
library/styles/whale/
├── tokens.tsx    STYLE token 表（配色/字体/画布/tilt）
├── shell.tsx     SHELL 外壳骨架
├── place.tsx     PLACE 摆位策略
└── title.tsx     TITLE 节拍小标题（可选：删掉此文件 = 该风格不要小标题）
```

`spec.json` 的 `style` 只写下面的 **id**，不要写具体颜色。

| id | 文件 | 名称 / 气质 | 画面基调 | 适合内容 |
|---|---|---|---|---|
| `paper` | `paper/` | 暖纸 · 知识拆解 / 方法论 | 米色点阵背景 `#F7F3EA`，白卡，蓝 / 琥珀 / 玫瑰点缀 | 方法步骤、清单、解释型口播（样片 `why-ai-expert`） |
| `ink` | `ink/` | 墨黑 · 科技 / AI / 硬核观点 | 深色背景 `#121722`，深蓝卡，高对比亮色 | 趋势判断、AI 观点、数据感（样片 `ai-workflow`） |
| `fresh` | `fresh/` | 清新 · 生活效率 / 清单 / 轻知识 | 薄荷绿背景 `#F2FAF7`，绿 / 琥珀点缀 | 生活技巧、效率清单、轻科普 |
| `whale` | `whale/` | 鲸语 · 萌系知识口播（**类原片风格包**） | 米色点阵 `#F6F1E6`，蓝 / 琥珀 / 玫瑰 + 蓝鲸吉祥物 + 扁平插画 | 三步清单、方法论、栏目化口播；想和拆解视频同风格时选它 |

**视觉契约（视觉全部归风格）**：每份风格必须导出三件套 + 一个 token，engine 不做任何视觉决策（连摆位都不做）：

```tsx
SHELL: React.FC<{ frame, ch, sub?, children? }>   // 外壳骨架：背景/进度/品牌/章节/字幕，放哪长什么样全归它；children 必须渲染
PLACE: (layout: string, items: any[], SZ) => [x, y][]   // 摆位策略：items 在内容区的坐标（SZ 是组件尺寸表，engine 传入）
TITLE: React.FC<{ text: string; opacity: number }>       // 节拍小标题：自带头部样式与位置（**可选件**——不提供 = 该风格整片不渲染小标题，spec/默认标题被忽略）
tilt:  number[]                                          // token：便签/印章的微倾斜角度序列
```

四件分别住在风格目录的 tokens.tsx / shell.tsx / place.tsx / title.tsx。engine 的职责只有：查表翻译（kind/motion 字符串→函数）、时序（错峰/入场门控/句末淡出）、动效应用、配音对齐、组合注册——**保证风格的视觉被正确解析显示**。四套风格刻意不同：whale 徽章式（标准摆位）/ paper 阅读式（紧凑间距+通顶细线）/ ink 记号式（摆位吸附 40px 网格，与背景网格对齐）/ fresh 居中式（宽松间距+右侧竖向进度条）。

**所有风格共用 token**（新增风格也必须给齐）：

- 画布：`W=1620`、`H=1080`、`FPS=30`；圆角 `r=18`、`rSm=12`。
- 字体：`"Noto Sans SC", "Microsoft YaHei", sans-serif`。
- 背景点阵：`paper / paperDeep / dot / dotSize / dotGap`。
- 文字：`ink / inkSoft / inkFaint`。
- 卡片：`card / cardBorder / cardShade`。
- 强调色 `accents`：`blue / amber / rose / jade / violet / red / ink`。
- 字幕与章节：`hi / subBg / subText / chapterBadge / chapterName / chapterNameText`。
- 进度与引用：`progress / progressTrack / quoteBg / quoteText`。

> `[[高亮]]` 会渲染成 `STYLE.hi` 色 + `fontWeight:900`，不需要在文案里写颜色。

`whale` 额外提供吉祥物/插画 token：`hero`、`heroDeep`、`heroLight`、`skin`、`blush`。其他风格没有这些字段，所以吉祥物只在 `whale` 下出现；其他风格沿用原来的鲸鱼小图标。

### 媒体装载器（library 根级 `*.tsx`，与 engine 同级）

**内容无关的通用播放器**——不画具体长相，只负责把外部素材（图片/Lottie JSON）装载渲染。住在 `library/` 根目录（`engine.tsx` 除外的一切根级 `.tsx` 都算），与组件同等「丢文件即登记」，build.py 分段内联。

| kind | 文件 | 尺寸 | 可用字段 | 作用 |
|---|---|---|---|---|
| `img` | `library/img.tsx` | 240×240（`w`/`h` 可覆盖） | `src`、`t`、`w`、`h`、`fit`、`pad`、`bare` | 显示一张真实图片（见「图片素材库」）；`bare:true` 去掉白卡边框 |
| `lottie` | `library/lottie.tsx` | 300×300（`w`/`h` 可覆盖） | `src`（json 素材名）、`t`、`loop`（默认 `true`） | Lottie 动画逐帧 seek；自动从本 item 出场帧开始（`from=ctx.at`），循环（见「Lottie 素材库」） |

| `wQuote` | `wQuote.tsx` | 1320×280 | `t`、`by`、`size` | 深色金句框：大引号 + 白字 + 署名 |

### 图标名 `icon`

图标来自 `_icons.tsx`，不是独立组件，只是组件的一个字段。可用名：

`expert`、`target`、`search`、`lock`、`clock`、`coins`、`doc`、`brain`、`check`、`cross`、`pen`、`box`、`whale`、`flag`、`bulb`

> 写错图标名不会报错，会回退成 `bulb`；外壳固定图标只剩 `flag`（鲸鱼已从外壳移除）。

### 扁平插画名 `illustration.name`

`whale` 风格包专用，比线性 `icon` 更接近原片：`calendar`、`shovel`、`magnifier`、`traffic`、`gear`、`compass`、`box`、`doc`、`coins`、`clock`、`target`、`bulb`。
写错会回退成 `bulb` 插画。

### 图片素材库 `library/assets/`（入库必须同步本表——AI 只认表，目录里没登记的素材对 AI 不存在）

`img` 组件显示的不是代码画的图，而是**真实图片文件**（PNG/JPG/WEBP/SVG）。素材按两级目录放：

- **共享素材**：`library/assets/**/<名字>.png` —— 任何片子都能引用，如 `library/assets/whale/calendar.png`。
- **单集私有**：`output/<id>/assets/<名字>.png` —— 只给这一集用，优先级高于共享。

`spec.json` 里用 `src` 写名字（不带扩展名）：`{ "kind": "img", "src": "calendar", "t": "定时间", "w": 300, "h": 300 }`。
`build.py` 的素材处理是**零拷贝**：私有素材（`output/<id>/assets/`）原地不动；共享素材构建时拷一份进本集 `assets/`；`DATA.assets` 只存 public-dir 相对路径，渲染经 `--public-dir` 伺服（与配音同一条链路）。

现有共享素材（`library/assets/whale/`）：

| src | 内容 | 原始尺寸 | 风格 |
|---|---|---|---|
| `calendar` | 日历 | 1024×1024 | 扁平、蓝/琥珀/玫瑰、米色底 |
| `clock` | 时钟 | 1024×1024 | 同上 |
| `magnifier` | 放大镜 | 1024×1024 | 同上 |
| `target` | 靶心 | 1024×1024 | 同上 |
| `gear` | 齿轮 | 1024×1024 | 同上 |

> 图片颜色是**固定**在文件里的，不跟风格 token 换色；代码画的组件（如 `illustration`）才会跟着换。想要图片换色得重新出图。**必须走 `src` 引用**，不要在 spec 里写文件路径。样片：`whale-images`（重建后 episode.tsx 仅 ~30KB）。
>
> Lottie 例外：JSON **解析成对象内联**进 `DATA.lottie`（不落盘不走 URL）——`animationData` 需同步可用，且 JSON 本就轻量。

### Lottie 素材库（入库必须同步本表——同上）

`lottie` 组件的 `src` 同样写**素材名**（不带扩展名），build.py 会扫描 `kind=lottie` 的项：
- 文件位置：`output/<id>/assets/<名字>.json`（本集私有，优先）或 `library/assets/**/<名字>.json`（共享）
- 处理方式：**JSON 解析成对象**内联进 `DATA.lottie`（不是 base64），渲染时传给 `<Lottie animationData>`
- 现有共享素材：`library/assets/lottie/pulse-dot.json`（蓝色圆点脉冲，240×240，90 帧 @30fps 循环，最小可跑样例）
- Lottie 文件来源：LottieFiles.com 等平台下载（注意授权），或 AE + Bodymovin 导出

### 强调色 `accent`

所有组件通用：`blue` / `amber` / `rose` / `jade` / `violet` / `red` / `ink`。
不写时用组件自己的默认值（如 `sticky` 默认 `amber`、`chip` 默认 `jade`、`stamp` 默认 `red`）。

## 3. 动效库 `library/motions/*.ts`

动效 id 写在 `items[].motion`（优先）、行级 `motion`（次选）；不写就按 `intent` 默认。
时长由 `D_xxx` 固定，spec 里不能改。

| id | 文件 | 帧数 | 运动 | 适合 |
|---|---|---|---|---|
| `pop` | `pop.ts` | 14 | 带回弹：`translateY 28→0`、`scale 0.6→1` | 快节奏强调、蹦出关键词 |
| `rise` | `rise.ts` | 18 | 柔和上浮：`translateY 60→0` + 淡入 | 清单、论据逐条出现 |
| `stamp` | `stamp.ts` | 16 | 盖章：`scale 1.8→1`、`rotate -18°→0` | 结论、定稿 |
| `slideLeft` | `slideLeft.ts` | 16 | 从左侧 `translateX -160→0` + 淡入 | 从左入场的并列项 |
| `slideRight` | `slideRight.ts` | 16 | 从右侧 `translateX 160→0` + 淡入 | 步骤、流程推进 |
| `flip` | `flip.ts` | 18 | 透视翻转 `rotateX 88°→0` + 淡入 | 对比、揭示 |
| `typeIn` | `typeIn.ts` | 24 | 不改变位移，输出 `typing` 比例；目前只有 `quote` 消费 | 金句逐字显现 |
| `fade` | `fade.ts` | 12 | 只做透明度 | 转场、标题淡入淡出 |
| `drop` | `drop.ts` | 16 | 从上方 `translateY -120→0` + 淡入 | 掉落式强调 |
| `shock` | `shock.ts` | 18 | 弹簧缩放 + 正弦震动 | 钩子、反常识开场 |
| `tilt` | `tilt.ts` | 20 | 从 `-10°` 摆到 `+4°` 后回稳 | 天平、权衡、对比倾斜 |
| `wobble` | `wobble.ts` | 22 | 回弹 + 正弦左右摆 `±6°` 递减 | 数据卡、吉祥物、便签活泼入场 |
| `unfold` | `unfold.ts` | 18 | `scaleX 0.2→1` + 轻微纵向展开 | 表格、流程、对比板揭开 |

`wobble` / `unfold` 属于 whale 套件动效，但纯时间函数、与风格无关，任何组件都能用。

`_common.ts` 提供 `clampOpt` 和 `easeOut`，是公共工具，不可作为 motion id。

## 4. 引擎排版 `library/engine.tsx`

### 布局 `layout`（取值由各风格的 `PLACE` 解释；engine 零摆位）

| 布局 | 摆位规则 |
|---|---|
| `center` | 所有 item 叠在中心 `(750, 350)` |
| `column` | 纵向排列，间距 34px，整体居中 |
| `row` | 横向排列，间距 40px，整体居中 |
| `grid` | 4 项时 2 列，否则最多 3 列；列宽 410 / 行高 210 / 间距 48×44 |
| `split` | 左右两列，x 为 `750±380` |
| `timeline` | 横向时间线，间距 `min(360, 1400/n)` |
| 其他 | 回退到 5 个预设散点 |

### intent → 默认配方（唯一定义处：`library/recipe.json`，生成期预计算进 beats）

| intent | 默认 layout | 默认 motion | stagger | 默认小标题 |
|---|---|---|---|---|
| `hook` | center | shock | 0 | 误区 |
| `claim` | center | pop | 0 | 观点 |
| `contrast` | split | flip | 5 | 对比 |
| `enumerate` | grid | pop | 3 | 并列 |
| `steps` | timeline | slideRight | 5 | 步骤 |
| `quote` | center | typeIn | 0 | 原话 |
| `checklist` | column | rise | 4 | 清单 |
| `proof` | row | rise | 4 | 论据 |
| `conclusion` | center | stamp | 0 | 结论 |
| `transition` | center | fade | 0 | （空） |

### 时间规则

- 每句 = 一页。配音用 edge-tts 生成，时长用 ffprobe 实测，再按 30fps 换算帧边界。
- item 出场：`sub.start + 5 + i × stagger`。
- 小标题：8 帧淡入，句末 6 帧淡出（不会逐句累积）。
- item：句末 7 帧淡出；`sticky` / `stamp` 有轻微固定倾斜。

## 5. `spec.json` 字段字典

| 字段 | 层级 | 必填 | 说明 |
|---|---|---|---|
| `id` | 根 | 是 | 片子 id，同时是 Remotion composition id；建议与目录名同名 |
| `title` | 根 | 是 | 片子标题 |
| `brand` | 根 | 否 | 左上角品牌字样，缺省用 `title` |
| `style` | 根 | 是 | `paper` / `ink` / `fresh` / `whale`（想用成套原片风格选 `whale`） |
| `voice` | 根 | 否 | edge-tts 音色，默认 `zh-CN-XiaoxiaoNeural` |
| `rate` | 根 | 否 | 语速，如 `+8%` |
| `chapters` | 根 | 是 | `[{badge, name, fromSub, toSub}]`，用字幕下标，不用帧号 |
| `lines` | 根 | 是 | 一句一页 |
| `text` | line | 是 | 口播文案，`[[...]]` 标高亮 |
| `intent` | line | 是 | 见上表；决定默认排版 / 动效 / 标题 |
| `items` | line | 是 | 组件数组，见第 2 节 |
| `motion` | line / item | 否 | 行级 / 单项动效；优先级见下 |
| `layout` | line | 否 | 覆盖 intent 默认布局 |
| `title` | line | 否 | 覆盖 intent 默认小标题；传 `""` 可隐藏 |
| `mascot` | 根 | 否 | **已停用**：引擎外壳不再渲染吉祥物，写了也不生效 |
| `mascot` | line | 否 | **已停用**：同上 |

**动效优先级：** `items[i].motion` ＞ 行级 `motion` ＞ `intent` 默认。
组件和动效是自由交叉组合的，不存在「某组件只能用某动效」的绑定。

## 6. 扩库登记规则

| 要加什么 | 改哪些地方 |
|---|---|
| 新组件 | `library/components/` 丢 `.tsx` 文件，内含 `c_组件名` 函数 + `SZ_组件名` 尺寸声明——**丢文件即完成全部登记**（三张表 build.py 自动生成），不用动 engine。**组件内可直接组合 §7 官方原语**（`Rect`/`evolvePath`/`Trail`/`Lottie`…）；本字典加一行。成套组件统一用 `w` 前缀并在「whale 成套组件」小节登记 |
| 新动效 | `library/motions/` 丢 `m_xxx` 与 `D_xxx` 文件——**丢文件即登记**（`MOTION_IDS` 从目录自动派生）；本字典加一行 |
| 新装载器（媒体播放器类） | `library/` **根级**丢 `.tsx`（`c_名字` + `SZ_名字`，纪律同组件；`engine.tsx` 名字保留）；本字典「媒体装载器」表加一行 |
| 新素材（图片 / Lottie） | 文件丢 `library/assets/**/`——代码零改动、丢文件即可用，**但 AI 只认字典表**：不登记 = 对 AI 不存在。§2「图片素材库 / Lottie 素材库」表加一行（src 名 / 内容一句话 / **原始尺寸**（宽×高，AI 据此配比例贴合的 `w`/`h`） / 风格备注）。同时核对表与目录一致（目录有而表没有 → 补；表有而目录没有 → 删行） |
| 新风格 | 建 `library/styles/<id>/` 目录：tokens / shell / place 三件必需，title 可选（可再加自有文件）；本字典加一行 |
| 改节奏规则 | 只改 `library/recipe.json` 与本字典表格（build.py 只读不持有） |

## 7. 官方原语（@remotion/* 包，build.py 公共 import 已带上）

组件片段里**可以直接使用**下列符号（import 行由 build.py 写在 episode.tsx 头部；没用到的会被打包器 tree-shake，不增体积）。包安装在项目根 `node_modules`，版本与 remotion 主包一致（4.0.537）。

| 来源 | 符号 | 干什么 |
|---|---|---|
| `@remotion/shapes` | `Rect` `Circle` `Ellipse` `Triangle` `Polygon` `Star` `Heart` `Pie` `Arrow` `Callout` `Spark` | 现成 SVG 图形组件（props 帧驱动，可配 fill/stroke/rounded） |
| `@remotion/paths` | `evolvePath` `getLength` `getPointAtLength` `interpolatePath` | 描线生长 / 沿路径取点 / 路径插值——连线、箭头「画出来」的标准做法 |
| `@remotion/noise` | `noise2D` `noise3D` | 确定性噪声（同 seed 同结果）——抖动、粒子感替代手写 sin 公式 |
| `@remotion/motion-blur` | `Trail` `CameraMotionBlur` | 运动残影 / 相机模糊——快速动效（shock、wobble）可加拖尾 |
| `@remotion/lottie` | `Lottie` `getLottieMetadata` | 已封装为 `lottie` 组件（§2）——spec 里 `items` 点 `kind: lottie` 即用，无需直接调 |
| `@remotion/gif` | `Gif` | GIF 组件（startFrom / playbackRate 帧驱动） |

未引入的两个：`@remotion/media-utils`（build 侧异步工具，将来音频分析用时在 build.py 调）；`@remotion/transitions`（引擎级转场机制，与 beats 时序模型冲突，暂不引）。

> 纪律不变：组件文件本身仍不写 import——要用官方原语就用上表符号名；需要新符号时在 `build.py` 的公共 import 行加（并同步本表）。
